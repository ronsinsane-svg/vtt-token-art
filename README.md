# vtt-token-art

Custom virtual-tabletop **token art** for Roll20 — AI-generated (Midjourney), then
tokenized (crop → circular mask → ring border) by the roll20-claude-bridge pipeline.

Images are served directly to Roll20 as a token `imgsrc` via
`https://raw.githubusercontent.com/ronsinsane-svg/vtt-token-art/main/<name>.png`
(public, clean paths — Roll20 strips query strings).
